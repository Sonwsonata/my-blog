this：

一句话规则

this 不是函数定义时决定的，而是函数“怎么被调用”决定的

最常见的 4 种情况

情况 1：普通函数调用

this === window（浏览器）
严格模式下是 undefined

情况 2：对象方法调用

this === obj

易错情况

this 不再是 obj
又变回 window / undefined

情况 3：箭头函数（重点）

箭头函数没有自己的 this

👉 这里 this 不是 obj
👉 而是 外层作用域的 this

情况 4：事件中的 this

事件回调里，普通函数的 this 会被浏览器自动绑定为“触发事件的元素”，箭头函数不会

this 总结

谁调用，this 就是谁（箭头函数除外）
